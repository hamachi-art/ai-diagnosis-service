# AIキャリア診断動作確認チェックリスト（Stage3）

対象：AIキャリア診断機能（診断フォーム・AI分析・結果保存・履歴・編集・削除）

## 前提

- 会員ログインが完了している（Google 認証または開発用モックログイン）
- ローカル開発サーバーが起動している（`npm run dev` → `http://localhost:3000`）
- 環境変数が設定されている
  - `AUTH_SECRET`
  - `MONGODB_URI`（診断結果の永続化）
  - `ANTHROPIC_API_KEY`（本番・AI分析本番相当の確認時は必須）
  - `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`（Google ログイン利用時）
- 開発環境（`AUTH_MOCK_MODE=true` または `NODE_ENV !== 'production'` かつ `ANTHROPIC_API_KEY` 未設定）では、AI分析は **モックロードマップ** で動作する
- MongoDB の `diagnoses` コレクションに診断結果が保存される

## 確認環境

- **ブラウザ**: Chrome / Edge
- **表示**: PC / タブレット / スマホ（レスポンシブ）
- **認証方式**: Google ログイン（本番相当）またはモックログイン（開発用）

## 5問の内容（参考）

| # | キー | ラベル | 質問 |
|---|------|--------|------|
| 1 | `careerAptitude` | 職業適性 | 得意なことや、周囲から「向いている」と言われる仕事・役割 |
| 2 | `skills` | スキル | 現在持っているスキルや経験（仕事・学習・趣味含む） |
| 3 | `interests` | 興味関心 | 仕事や学びに関して、興味がある分野・テーマ |
| 4 | `values` | 価値観 | キャリアで大切にしたい価値観 |
| 5 | `workStyle` | 働き方 | 理想の働き方や環境の希望 |

### 11. API 各エンドポイント

#### `GET /api/diagnosis`

- [ ] 認証済みで呼ぶと 200 と診断一覧 JSON 配列が返る
- [ ] 各要素に `id`・`answers`・`careerRoadmap`・`createdAt`・`updatedAt` が含まれる
- [ ] 新しい順に並んでいる

#### `POST /api/diagnosis`

- [ ] リクエスト body: `{ "answers": { careerAptitude, skills, interests, values, workStyle } }`
- [ ] 正常時 201 と作成された診断 JSON が返る
- [ ] `answers` 欠落・空文字の場合 400 が返る
- [ ] 不正 JSON の場合 400（`Invalid JSON`）が返る
- [ ] AI分析失敗時 500 が返る

#### `GET /api/diagnosis/{id}`

- [ ] 認証済み・自分の診断の場合 200 と診断 JSON が返る
- [ ] 存在しない ID の場合 404 が返る

#### `PUT /api/diagnosis/{id}`

- [ ] `answers` または `careerRoadmap`（または `result`）のいずれかが必須
- [ ] 両方欠落の場合 400（`answers or careerRoadmap is required`）が返る
- [ ] 正常時 200 と更新後 JSON が返る
- [ ] 存在しない ID の場合 404 が返る

#### `DELETE /api/diagnosis/{id}`

- [ ] 正常時 200 と `{ "ok": true }` が返る
- [ ] 存在しない ID の場合 404 が返る

## 補足（トラブルシューティング）

| 症状 | 確認ポイント |
|------|-------------|
| 診断ボタン押下後に 500 エラー | `ANTHROPIC_API_KEY` の設定（本番は必須） |
| 診断結果が保存されない | `MONGODB_URI` の接続、MongoDB の起動状態 |
| 履歴が空のまま | `diagnoses` コレクションの有無、ユーザー ID の一致 |
| 保護ルートが開けてしまう | `middleware.ts` の `matcher` 設定、`AUTH_SECRET` の設定 |
| 編集・削除が失敗する | ネットワークタブで API レスポンス確認、診断 ID の有効性 |
| 開発環境で AI が動かない | `AUTH_MOCK_MODE=true` または `NODE_ENV=development` でモック動作を確認 |
| 他ユーザーの診断が見える | `userId` によるアクセス制御、`getDiagnosisById` のフィルタ |
